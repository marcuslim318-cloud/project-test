# 项目落地计划

代码仓库：<https://github.com/marcuslim318-cloud/project-test/tree/main>

开源协议：[MIT License](../LICENSE)；本项目当前为比赛原型，下列时间为预估，非承诺排期。

## 0–30 天：可试点 MVP

将 JSON 替换为 Supabase/PostgreSQL；把 Gemini Key 移到后端；完成企业、员工、审批规则、收据对象存储与审计日志。与 3–5 家 SME 进行费用收据试点。

## 31–60 天：合规与协作

接入 MyInvois 沙盒与 LHDN API，验证 TIN/UUID/状态（当前仅为模拟判定）；增加公司科目表、预算、导出和会计师复核工作流。

## 61–90 天：多入口与商业化

完成 Meta WhatsApp Business Cloud API、Webhook 与模板消息（当前仅前端模拟按钮）；上线 SaaS 套餐、用量计费、监控、备份及隐私政策。

成功指标：收据字段准确率、人工审核率、收据到入账时间、重复报销拦截数、活跃企业数与每企业每月收据量。
