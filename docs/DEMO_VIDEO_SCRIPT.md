## 2. 旁白全文（可直接照着念）

1. 把一张收据，变成一套可追溯的财务决策。
2. 小微企业的员工总把收据发到聊天群，老板和会计要反复确认金额、类别、是否已报销，最后才看得到结果。
3. 员工只需提交收据。AI 读取商户、日期、金额、税额与类别，写入共享审核队列；员工立刻看到“已提交”状态。
4. AI 不会自己决定入账。审核中心会列出所有待审核单据，低置信度、重复、缺 MyInvois 信息的项目都会标记出来，由管理员做主。
5. 管理员确认后，系统生成可追溯的复式分录，报表和审计轨迹实时更新。
6. 员工不必反复追问；老板能更早看到费用、利润与现金流变化。
7. WhatsApp 入口当前是模拟接入，用于展示消息如何进入同一审核队列；生产版才接入 Meta Cloud API 与 MyInvois/LHDN 后端验证。
8. 员工提交，AI 理解，管理员负责，账目可追溯。代码与文档见 GitHub。

## 3. 录制前置检查（开录前逐项打勾）

1. [ ] 电脑可运行 Node：`node --version` ≥ 20（本机用 Codex 运行时 `C:\Users\User\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe`）。
2. [ ] 删除 `data.json` 获得干净数据（保留会自动重建空库）。
3. [ ] `npm start` 启动成功，浏览器打开 `http://localhost:8000`，缩放 100%。
4. [ ] 准备一张**无敏感信息**的样例收据图片（Grab、便利店、餐饮任选）；同时备份「使用演示收据」按钮作为兜底。
5. [ ] 录屏软件设为 1920×1080、60fps；准备麦克风。
6. [ ] 关闭无关通知/弹窗；浏览器开无痕窗口，避免登录态残留。
7. [ ] AI 设置：不填 Gemini Key 也能全程演示（演示模式）。若要用真实识别，需先在「AI 设置」粘贴本地 Key。

## 4. 录屏步骤（对镜头逐步操作）

1. 开 0 号镜头字幕（可用剪映/Pr 加标题）。
2. 镜头 1：切到浏览器登录页；停留 3 秒再操作。
3. 镜头 2：以 `employee / emp123` 登录 → 上传区拖入收据图片 → 点「开始 AI 审核」；若识别慢，点「使用演示收据」→ 等待“已提交”toast 出现。
4. 镜头 3：退出登录，以 `admin / admin123` 登录 → 点左侧「审核中心」→ 展示队列中所有待审核单据 → 点击第一张 → 依次展示：置信度、AI 审核结论、风险检查项、建议分录。
5. 镜头 4：点「确认并入账」→ 自动跳转「财务报表」，依次展示损益表、资产负债表摘要、总账审计轨迹。
6. 镜头 5：退出，以 `employee / emp123` 重新登录 → 展示“已审核并入账”通知。
7. 镜头 6：管理员进入「WhatsApp 收据」→ 画面出现“模拟接口 · 未发起真实 API”标签 → 点「模拟收到一张收据」→ 展示自动回复与“生产版接入清单（待配置）”。
8. 镜头 7：回首页/打开 README，口播 GitHub 链接与 MIT 协议；结束。
