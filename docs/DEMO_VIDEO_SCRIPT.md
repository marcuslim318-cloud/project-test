# Demo 视频脚本与分镜（约 2 分 45 秒）

## 镜头 1：真实场景（0:00–0:25）

画面：手机拍摄 Grab、餐厅或办公用品收据，再切到 LedgerLens 登录页。

旁白：`小微企业的员工经常把收据发到聊天群。老板和会计需要重复确认金额、类别和是否已报销，最后才看得到财务结果。`

## 镜头 2：员工交互（0:25–0:55）

画面：使用 `employee / emp123` 登录，上传真实收据；若网络不稳定，点击“使用演示收据”。

旁白：`员工只需提交收据。AI 读取供应商、日期、金额、税额与费用类别，并把结构化数据发送到共享审核队列。员工立即收到“已提交”的状态。`

## 镜头 3：管理员审核（0:55–1:40）

画面：退出，以 `admin / admin123` 登录；打开审核中心，展示原始收据、置信度、风险和复式分录；点击确认入账。

旁白：`AI 不会自己决定入账。低置信度、重复和异常项目需要管理员审核。管理员确认后，系统生成可追溯的复式分录。`

## 镜头 4：用户价值（1:40–2:05）

画面：财务报表与总账审计轨迹，再以员工账号重新登录显示“已审核并入账”通知。

旁白：`一张收据现在能实时影响费用、利润和审计轨迹；员工不必反复追问，老板也能更早发现经营变化。`

## 镜头 5：未来接入与落地（2:05–2:35）

画面：WhatsApp 收据页，点击模拟收到消息；展示 PPT 的 MyInvois / WhatsApp 路线图。

旁白：`比赛版本演示 WhatsApp 消息如何进入同一审核队列。生产版将接入 Meta Cloud API 和 MyInvois/LHDN 后端验证。`

## 收尾（2:35–2:45）

画面：产品首页与一句话定位。

旁白：`LedgerLens AI：员工提交，AI 理解，管理员负责，账目可追溯。`

## 录制清单

1. 启动 `npm start`，浏览器打开 `http://localhost:8000`。
2. 清空或保留 `data.json` 前确认演示数据干净。
3. 录屏为 1920×1080；打开浏览器缩放至 100%。
4. 预先准备一张没有敏感信息的样例收据；同时准备演示模式作为备份。
5. 全程明确 WhatsApp/MyInvois 是“模拟接入/生产路线”，避免夸大能力。
