**产品铁律（视频中必须严格遵守）：**

- 报表是管理层草稿，正式 MPERS/MFRS 报表须会计师审核。
- 不要出现真实收据的个人信息；如需收据画面，使用示例或打码。

## 按工具类型的附加强化提示

**（A）配音/字幕/成片型（剪映、HeyGen、Descript 等，最推荐）**
> 画面用真实录屏，仅让 AI 做配音+字幕+剪辑。附加指令：
> "播放以下中文旁白（见分镜），语气：清晰、专业、略带温度，语速约每分钟 220 字；为每段自动生成中文字幕；结尾添加 GitHub 网址字幕。"

**（B）文生视频型（Sora / Veo / Runway / Pika）**
> 画面由 AI 生成。附加指令：
> "按分镜生成 '真实手机拍摄收据'、'仪表盘/财务报表界面'、'收款单据列表' 等镜头；界面文案用中英文混合的通用财务词汇（如 Receipt、Review、Ledger、Profit），避免出现真实品牌与个人信息。"

**（C）数字人播报型（HeyGen 等）**
> 附加指令：使用干练商务形象、深蓝背景、中文字幕同步、可接"分镜 0–7"逐段口播。

**（D）语音文本给 TTS 的纯文本**
> 即「分镜与旁白」中 8 段旁白，去掉画面描述后直接投喂 TTS。
